About the Project

Learn more about Smart Home Energy Prediction.

🏡🔋🌿

Smart Home Energy Prediction

A machine learning based web application that predicts household appliance energy consumption using environmental conditions such as temperature, humidity and lighting. The project helps users understand their energy usage and provides simple suggestions to reduce electricity consumption.

⚙️

Technology Stack

HTML, CSS, JavaScript, Python (Flask), MongoDB (PyMongo), Scikit-learn

📊

Dataset

Appliances Energy Prediction (UCI Repository)
3,000 records, 9 columns

🎯

ML Model

Linear Regression
Evaluation: R² Score, MAE
